# Marketing skills

The 50 marketing skill folders here come from
https://github.com/coreyhaines31/marketingskills (MIT, see
`MARKETINGSKILLS-LICENSE`), commit `dda3841f0b294e01e93b1541486beefbfab0915e`.
The upstream `evals/` folders were left out — they test the skills and aren't
loaded by Claude.

Most skills read a shared context file, `.agents/product-marketing.md`.
Run the `product-marketing` skill first to create it for Dofixo.

To update: re-copy `skills/*` from upstream over these folders.
