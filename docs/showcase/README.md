# ویترین دوفیکسو — اسکرین‌شات‌ها و موکاپ‌ها

همهٔ تصاویر این پوشه از اجرای واقعی برنامه گرفته شده‌اند: Postgres محلی، API و فرانت روی
`localhost`، و داده‌های فیک که **از طریق خود API** وارد شده‌اند. پس موجودی انبار، میانگین
قیمت خرید و شماره‌گذاری فاکتورها همه از منطق تجاری واقعی عبور کرده‌اند.

## داده‌های دمو

- کارگاه «تعمیرگاه موبایل و لپ‌تاپ آرین»، ورود با `09121234567` / `Demo@12345`
- ۶ پرسنل (۱ سوپر ادمین، ۱ ادمین، ۴ تکنسین)، ۴۲ مشتری، ۶۴ دستگاه در وضعیت‌های مختلف
- ۴ دسته و ۲۲ کالا، ۱۳ فاکتور خرید، حدود ۷۰ فاکتور فروش و ۴۴ فاکتور تعمیر در ۴ ماه گذشته
- کیف پول پیامکی با یک شارژ ۲ میلیون تومانی و تاریخچهٔ پیامک‌های ارسالی

## پوشه‌ها

- `screenshots/` — ۲۷ تصویر: همهٔ صفحه‌ها (۱۴۴۰px، روشن)، چند مودال، سه صفحه در تم تیره و دو صفحه موبایل (۴۲۰px)
- `mockups/` — سه موکاپ ۳۸۴۰×۲۴۰۰:
  1. `01-hero-laptop-phone.png` — لپ‌تاپ و موبایل روی پس‌زمینهٔ آبی برند، مناسب هدر سایت
  2. `02-light-dark-browsers.png` — دو پنجرهٔ مرورگر برای نمایش تم روشن و تیره
  3. `03-perspective-wall.png` — دیوار سه‌بعدی از ماژول‌ها، مناسب شبکه‌های اجتماعی و اسلاید
- `source/` — اسکریپت‌هایی که این‌ها را ساختند

## ساخت دوباره

```bash
# بعد از migrate و seed (SEED_ADMIN_USERNAME=09121234567، SEED_ADMIN_PASSWORD=Demo@12345)
# و با RATE_LIMIT_LOGIN=0 در backend/.env
node source/demo-data/fake-data.mjs
node source/demo-data/device-invoices.mjs
psql "$DATABASE_URL" -f source/demo-data/fix-dates.sql   # با اتصال مالک (dofixo)، فقط یک‌بار

# فرانت باید روی localhost:5173 باشد، نه 127.0.0.1 — کوکی refresh با SameSite=Strict
# بین 127.0.0.1 و localhost:5001 فرستاده نمی‌شود و هر صفحه به /login برمی‌گردد.
node source/demo-data/shots.cjs

# موکاپ‌ها: تصاویر screenshots، فونت‌های Peyda و لوگو را کنار HTML بگذارید، سپس
node source/mockups/render.cjs mockup-1 mockup-2 mockup-3
```

`fix-dates.sql` تاریخ ایجاد ردیف‌ها را با تاریخ ورود دستگاه و تاریخ فاکتور هم‌سو می‌کند
(وگرنه همه «امروز» ساخته شده‌اند) و تاریخچهٔ کیف پول پیامکی را می‌سازد. فقط روی پایگاه‌دادهٔ
توسعه اجرا شود.
